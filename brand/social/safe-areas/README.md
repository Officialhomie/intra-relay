# Safe-area guides

These visible guides are review assets and must not be published.

- `intra-safe-area-x` — protects the profile-overlap side and edge crops.
- `intra-safe-area-linkedin` — protects the logo-overlap and edge zones.
- `intra-safe-area-youtube` — marks the centered all-device banner area.
- `intra-safe-area-story` — protects content from common top and bottom controls.

Platform rendering changes over time. Validate final files in each live uploader.

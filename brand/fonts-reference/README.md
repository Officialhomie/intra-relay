# Font reference

Intra does not currently bundle, self-host, or download fonts. No font file is
licensed or approved for redistribution in this asset package.

The implemented stacks are defined in `src/styles/tokens.css` and recorded in
`../brand.json` and `../BRAND-GUIDELINES.md`.

Fraunces is not loaded or used. “Faire Octave / Fraunces” appears only in
ADR-009 as a proposed reference that was replaced by the current system-serif
stack. Do not add a Fraunces file to this directory without a new identity
decision and a documented license/source.

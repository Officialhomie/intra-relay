# Wordmark status

No canonical vector wordmark exists.

The current product lockup uses the Handoff mark followed by live text “Intra”
in the system sans, weight 600, tight tracking, with a `0.5rem` gap. Keeping it
as text avoids freezing a platform-dependent system font into an inconsistent
outline asset.

A dedicated wordmark and fixed vector lockup are future design work. They were
not created during this extraction.
